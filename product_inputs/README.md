# 製品入力

このディレクトリは、共通product入口が既定で参照する製品入力ファイルを保持する。

- `b25_multi2_parameters`: B25 MULTI2固定parameter入力。形式・供給・配置・アクセス条件は `../tuner_hal2/INTEGRATION.md` を正とする。
- `bcas_keys`: Yakisoba credential入力。供給・秘密情報の取扱い・配置・アクセス条件は `../cas_plugin/INTEGRATION.md` を正とする。

このREADMEでは各入力のbyte layout、値、上書き手順、製品統合条件を再定義しない。
