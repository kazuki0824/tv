# Maleicacid TV 入力サービス

このディレクトリは Android TV の `TvInputService` 実装を含む。

## 文書案内

- 設計判断、公開境界、状態遷移、TvProvider 利用、ライブ視聴は `DESIGN_JA.md` を参照する。
- product 統合条件は `INTEGRATION.md` を参照する。
- TIS 固有の実装規約は `CODE_CONVENTION.md` を参照する。
- 変更履歴は `CHANGELOG.md` を参照する。

利用開始時は、`INTEGRATION.md` の product package、権限、ビルド・実機確認手順と、`DESIGN_JA.md` の公開契約を確認する。
